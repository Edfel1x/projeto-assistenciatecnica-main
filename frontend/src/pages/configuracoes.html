Sobre o BCDADOS

Sistema de gerenciamento para assistência técnica. O frontend (Vite + JavaScript) consome uma API REST em Flask, que aplica as regras de negócio e persiste os dados no MySQL. Nenhuma credencial do banco está disponível no navegador.
